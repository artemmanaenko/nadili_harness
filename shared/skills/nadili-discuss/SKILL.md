# Nadili discussion

Read `AGENTS.md` and only focused product authorities. Discuss the outcome, constraints,
tradeoffs and failure cases with the owner. Offer concrete alternatives; for a design task,
present at least two meaningfully different design options. Recommend one with reasons, but
preserve the owner's decision.

Do not create a Linear issue, worktree, branch, spec, plan or implementation artifact during
discussion. An explicit instruction to **plan** enters `nadili-plan`; an explicit instruction
to **implement** applies to an approved ready item. A request to finish/integrate an existing
patch or concrete bounded fix enters `nadili-hotfix` without retrospective planning.
